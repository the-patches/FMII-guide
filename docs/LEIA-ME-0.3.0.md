# FMII-Recomp 0.3.0

[Português](#português) · [English](#english)

## Português

Mod de Stevan para **Yu-Gi-Oh! Forbidden Memories Recompiled 0.3.1-preview.2**. Use uma imagem BIN americana do jogo base (SLUS-01411). O mesmo pacote inclui código para Windows e Android arm64. A versão Android ainda aguarda teste em aparelho.

### Novidades

- As **518 cartas da expansão** têm arte ampliada e miniatura com Texturas HD. Os enquadramentos de Polymerization e Chimaera, the Master of Beasts ainda estão em revisão.
- Foram ajustadas 555 molduras e padronizados os nomes de 75 cartas da expansão.
- Horakhty recuperou a descrição original e agora tem **0 ATK / 0 DEF**. A vitória imediata ao ser invocado com a face para cima continua valendo.
- A descrição de Jinzo explica que ele bloqueia armadilhas de destruição dos dois lados enquanto está com a face para cima.

### Instalação

- **Windows.** Feche o Recomp, substitua a pasta anterior do mod pela pasta `FMII-Recomp` do ZIP e mantenha seu save do jogo. O manifesto deve ficar em `mods/FMII-Recomp/mod.json`. Ative o mod em **Game > Mods**.
- **Android arm64.** No painel **Mods** do Recomp, escolha **Import mod...**, selecione o ZIP, ative FMII-Recomp e reinicie.
- **Texturas HD** começa desligada. Para ativá-la, abra as configurações do mod e reinicie o jogo.

[Guia do jogador](https://the-patches.github.io/FMII-guide/)

## English

Stevan's mod for **Yu-Gi-Oh! Forbidden Memories Recompiled 0.3.1-preview.2**. Use a US BIN image of the base game (SLUS-01411). The same package contains code for Windows and Android arm64. The Android build still awaits on-device testing.

### What's new

- All **518 expansion cards** have HD large artwork and thumbnails. The framing of Polymerization and Chimaera, the Master of Beasts is still under review.
- Updated 555 card frames and standardized 75 expansion card names.
- Horakhty's original description is back, and it now has **0 ATK / 0 DEF**. Summoning it face up still wins the duel immediately.
- Jinzo's description now explains that neither player can activate destructive traps while it is face up.

### Installation

- **Windows.** Close Recomp, replace the older mod folder with the ZIP's `FMII-Recomp` folder, and keep your in-game save. The manifest should be at `mods/FMII-Recomp/mod.json`. Enable the mod under **Game > Mods**.
- **Android arm64.** In Recomp's **Mods** panel, choose **Import mod...**, select the ZIP, enable FMII-Recomp, and restart.
- **HD Textures** defaults to off. Turn it on in the mod settings and restart the game.
